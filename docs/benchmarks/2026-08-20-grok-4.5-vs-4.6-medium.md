# Grok 4.5 Medium vs Grok 4.6 Medium semantic ingest benchmark

Date: 2026-08-20

## Decision

Keep Grok 4.5 Medium as the recommended Grok ingest profile for v0.3.0.
Grok 4.6 Medium is qualified as a viable alternative, but this single matched
run did not show a quality or latency advantage.

Both models completed every provider invocation with `end_turn`. Neither run
produced a permission cancellation after the Grok adapter was changed to use
only `--always-approve` for headless execution.

This is a semantic and operational qualification, not a host-isolation
qualification. `--always-approve` grants the detached Grok worker broad tool
execution, and the benchmark fixtures contained only trusted inputs. v0.3.0
must not use this result to justify unattended ingestion of untrusted or
collaborator-controlled content. The current trust boundary and deferred
least-privilege work are documented in the README, manual, and TODO.

## Semantic findings

The blind evaluator saw candidate identifiers only. Candidate 001 mapped to
Grok 4.5 Medium and scored 95/100. Candidate 002 mapped to Grok 4.6 Medium and
scored 94/100. Confidence was high and the evaluator's forbidden-path audit was
empty.

Grok 4.5 produced the more compact retrieval artifact. It fully supported all
eight benchmark questions, including why voice-of-customer source groups stay
separate so that provenance remains visible.

Grok 4.6 was slightly more exhaustive on transcript and example detail and left
a cleaner final Git state. Its authored profiling page contained a full avatar
definition, so the deterministic check for the literal phrase `customer
avatar` was a checker false negative. However, the authored pages did not state
the reason for keeping the voice-of-customer source groups separate, leaving one
retrieval answer partial in the qualitative review.

Both models preserved claim boundaries. Neither promoted external advice,
reported figures, machine-transcript wording, psychology claims, health
examples, or conversion anecdotes into Naturbiss facts.

## Process and durability caveats

- Grok 4.5 ended Case 3 with one uncommitted schema-proposal modification.
- Both runs retained the duplicate source in `inbox/` alongside its canonical
  raw copy.
- Both runs left a raw bundle unarchived despite six manifest references and a
  schema threshold of five.
- Both root indexes linked missing empty-category indexes. This did not impair
  any benchmark retrieval question.

These deductions explain why neither semantic score is perfect. Grok 4.6's
cleaner final state earned a higher protocol score, but it did not offset 4.5's
small completeness and retrieval advantage.

## Method

- The two configurations ran sequentially in independent temporary wiki and
  Git fixtures.
- The prompt, source documents, three cases, skill snapshot, adapter snapshot,
  effort level, and deterministic grader were identical.
- Both invocations used Grok CLI 1.0.5, `--reasoning-effort medium`,
  `--always-approve`, `--max-turns 150`, `--no-memory`, and `--no-subagents`.
- The skill snapshot was based on repository commit
  `9a7076e619d77880fefe76c85b0b6a8319ab09ac` plus the pending v0.3.0 adapter
  and documentation diff.
- Adapter snapshot SHA-256:
  `468882ef6821c796f277bd85be59efb571fb7ad147c6943ae79bd0339173bc9a`.
- Ingest skill snapshot SHA-256:
  `0f0f730c91bbe79cb0884605347baa760e764af93e362676d15abced2d2f13ea`.
- A separate Codex evaluator received only anonymized candidate artifacts,
  frozen sources, the rubric, and evaluator instructions. Candidate mapping and
  provider metrics were withheld until its files and arithmetic were validated.

This is one matched run per model, not a variance study. It is sufficient to
show that the corrected adapter executes both profiles and that 4.6 did not win
this workload. Recommending 4.6 as the default would require repeated runs or a
new workload showing a consistent advantage.

## Dated follow-up: 2026-08-21 mixed-media default

This benchmark and its Grok 4.5 recommendation remain the authoritative dated
result for the tested text-ingest workload. A later
[vision transport benchmark](2026-08-21-grok-4.6-native-acp-image-qualification.md)
provided the new workload contemplated above: 16 preselected images across
three model and transport configurations. Only Grok 4.6 Medium with native ACP
image content blocks qualified for unattended multimodal ingestion.

The general mixed-media recommendation therefore moved to Grok 4.6 Medium with
native ACP image transport. This does not alter the 95/100 versus 94/100 text
scores above. The later matrix did not test Grok 4.5 with native image input,
so it does not prove universal model superiority or fully isolate every model
and transport interaction.
