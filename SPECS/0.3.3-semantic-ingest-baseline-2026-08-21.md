## Interpretation

The first five floor cases show that the current ingester can route simple
single-object captures into the right top-level category. That contradicts the
earlier worry that every source always lands in `concepts`.

The same five cases still fail the current heuristic claim coverage checks. This
means the baseline is useful, but the scoring must be reviewed manually before
treating failures as product regressions.

The multi-object cases show the current ingester can create multiple wiki
objects from one source. The main weakness is not a total failure to split. It
is over-absorption: a concept or entity page often carries claims that should
belong primarily to another entity, query, or idea page. This is visible in
`0006`, `0007`, and `0009`.

`0008` is a clean positive control: the ingester held a low-evidence source and
created no pages. `0010` shows a separate faithfulness issue, where unsupported
or overconfident claims still leak into generated pages.
