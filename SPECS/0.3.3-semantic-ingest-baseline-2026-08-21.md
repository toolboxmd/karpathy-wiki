## Result Summary

The baseline now has valid provider results for all ten MVP fixtures. Cases
`0001` to `0005` completed in the primary run. Cases `0006` to `0010` initially
failed because Grok Build usage balance was exhausted, confirmed by diagnostic
stderr showing HTTP `402 Payment Required`; after usage was restored, those
cases were rerun and all completed with provider exit code `0`.

Manual review found that the first heuristic scorer over-counted failures:
negative guardrail text such as "does not exist" was treated as an unsupported
positive claim, and cross-linked pages could be selected instead of the page in
the required category. The runner was updated to rescore existing snapshots,
prefer title/path matches in the expected category, ignore negated forbidden
claims, strip frontmatter from claim checks, and preserve numeric/code tokens
such as `127.0.0.1:7420`.

## Interpretation

The final rescore shows that the current ingester passes all ten MVP fixtures
for `grok-4.6 medium`. The earlier worry that every source lands in `concepts`
is not supported by this benchmark. The ingester creates entities, concepts,
queries, ideas, and projects, and it can split one source into multiple object
pages.

The more important lesson is methodological: the benchmark scorer must be
reviewed with the generated pages before using it to justify a skill patch. The
first scorer was too naive for negative guardrail prose and cross-linked pages.
After the scorer fix, the evidence does not justify changing
`skills/karpathy-wiki-ingest/SKILL.md` yet.
